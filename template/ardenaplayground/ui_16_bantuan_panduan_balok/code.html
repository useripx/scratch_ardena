Sebutkan objek nama sprite, arah gerak koordinat (sumbu X/Y), kondisi sentuhan, serta nilai variabel secara eksplisit.

Tanya Jawab Umum & Troubleshooting

Solusi instan untuk kendala pembuatan kode dan pemahaman batas kapabilitas mesin Ardena MVP.

Ardena Playground MVP dibangun di atas mesin eksekusi Scratch VM 3.0 resmi MIT yang secara arsitektural berbasis koordinat 2D (480x360 piksel). Pembatasan ini disengaja untuk menjaga performa di perangkat Chromebook/laptop sekolah tanpa GPU diskrit, serta menjamin kode Scratch yang dihasilkan 100% aman untuk edukasi pemrograman dasar tanpa risiko jaringan eksternal.
Tidak. Setiap kali Anda mengubah balok atau mendapatkan kode baru dari Copilot, sistem menyimpannya ke IndexedDB lokal di browser Anda. Namun, data dapat terhapus jika Anda membersihkan cache browser (Clear Site Data). Untuk keamanan cadangan, gunakan tombol Ekspor .sb3 di menu bar editor utama.
Format ekspor Ardena 100% identik dengan standar Scratch 3.0. Cukup klik menu Berkas > Unduh ke Komputer (.sb3) di editor. Kemudian buka scratch.mit.edu, buka editor online mereka, lalu pilih File > Load from your computer. Semua sprite, skrip balok, dan suara akan terbuka tanpa perubahan!
Peringatan ini dipicu oleh modul AST Verifier saat AI Copilot menghasilkan balok yang tidak didukung atau instruksi terlalu rumit. Solusinya:
  1. Sederhanakan instruksi Anda menjadi 1 aksi per kalimat (lihat Prinsip Spesifik di atas).
  2. Gunakan tombol "Coba Perbaiki Otomatis" pada banner error recovery.
  3. Pastikan Anda tidak meminta variabel atau efek grafis di luar standar 2D Scratch.
